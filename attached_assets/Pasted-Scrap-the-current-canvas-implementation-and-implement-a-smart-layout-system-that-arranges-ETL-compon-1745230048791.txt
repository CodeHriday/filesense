Here's a breakdown of how it works and how you can replicate similar behavior in your React Flow-based ETL tool:

How the stages should be Arranged
	1	Left-to-Right Layout:
	◦	Components (called "stages") are arranged so that data flows from left to right.
	◦	The start of the pipeline (e.g., input sources) are placed on the far left.
	◦	As components depend on other components, they are placed to the right of them.
	2	Vertical Separation by Branch:
	◦	If two branches originate from the same node (e.g., after a Filter or Split), they are arranged vertically, to avoid overlaps and improve readability.
	3	Spacing Between Nodes:
	◦	Fixed spacing (e.g., x + 250px, y + 100px) between parent and child nodes to give a clean, spaced layout.
	4	Automatic Rearrangement:
	◦	If you connect/disconnect stages, Matillion recalculates positions to maintain readability and avoid overlap.

How You Can Implement This in React Flow
1. Dependency Graph + Topological Sort
	•	Treat your ETL components as nodes in a graph.
	•	Draw edges based on dependencies (e.g., Join depends on two upstream sources).
	•	Apply topological sort to determine execution order.
2. Calculate Node Positions Based on Depth

function layoutNodes(nodes, edges) {
  const nodeMap = new Map();
  nodes.forEach((node) => nodeMap.set(node.id, { ...node, inEdges: [], outEdges: [] }));

  // Build graph relationships
  edges.forEach(({ source, target }) => {
    nodeMap.get(source).outEdges.push(target);
    nodeMap.get(target).inEdges.push(source);
  });

  const levels = new Map(); // nodeId -> level
  const visited = new Set();

  function dfs(nodeId, depth = 0) {
    if (visited.has(nodeId)) return;
    visited.add(nodeId);
    levels.set(nodeId, Math.max(levels.get(nodeId) || 0, depth));
    for (const next of nodeMap.get(nodeId).outEdges) {
      dfs(next, depth + 1);
    }
  }

  // Start from root nodes (no inbound edges)
  nodes.forEach((node) => {
    if (nodeMap.get(node.id).inEdges.length === 0) {
      dfs(node.id);
    }
  });

  // Apply positions based on levels and vertical index
  const positioned = {};
  for (const [nodeId, level] of levels.entries()) {
    if (!positioned[level]) positioned[level] = 0;
    nodeMap.get(nodeId).position = {
      x: level * 250, // horizontal spacing
      y: positioned[level] * 120, // vertical spacing
    };
    positioned[level]++;
  }

  return Array.from(nodeMap.values());
}
3. Use This Logic in React Flow
Once you calculate positions, feed it to your React Flow graph like this:
