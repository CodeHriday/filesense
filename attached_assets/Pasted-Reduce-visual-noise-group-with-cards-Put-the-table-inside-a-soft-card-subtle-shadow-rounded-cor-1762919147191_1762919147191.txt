Reduce visual noise & group with cards

Put the table inside a soft card (subtle shadow, rounded corners, light background) — this isolates content from the page background.

Collapse the giant empty area above the table: reduce top padding under the page title (title + short subtitle, then controls).

Improve typography hierarchy

Use a clear type scale: Page title (30–36px), section title (18–20px), table body (14px).

Increase line-height and reduce letter-spacing for table rows for readability.

Use a single font-family across app (e.g., Inter / system-ui fallback).

Left navigation: reduce weight & improve active state

Narrow the sidebar slightly, use compact spacing and smaller icons.

Use a clear active indicator: colored left border or filled rounded pill; keep it subtle (not heavy blue box).

Use hover states and transitions for sidebar items.

Header: declutter & align

Move small controls (theme toggle, notifications, user) to the right. Keep header height consistent and a thin bottom border rather than a heavy background color.

Replace the large solid blue header with a white or very light background + subtle bottom shadow — makes content stand out more.

Table improvements

Use zebra striping or very subtle row separators (avoid thick horizontal lines).

Add hover highlight on rows and pointer on clickable rows.

Align columns consistently; left-align name/description, right-align dates/counts.

Reduce column padding slightly to fit more content and improve scanability.

Add an affordance for expandable rows (chevrons) with consistent alignment.

Badges & status pills

Use consistent badge styles (same height, consistent padding, border-radius). Use accessible color contrast for status text (white on colored pill or dark text on light pill).

Avoid using saturated green/blue borders with white backgrounds and tiny text — pick filled or outlined style consistently.

Search & filters

Place search input and checkboxes in a compact toolbar above the table (left: search, right: actions). Use a search icon inside the input and a clear placeholder.

Add a small “filters” button grouping vendor, type, status (future).

Actions

Use a clear action column with consistent icon buttons (use 24px icons, light hover background).

Use tooltips for actions to explain functionality.

Spacing & alignment

Use consistent spacing scale (8px base). Reduce extra left/right padding in main content.

Align the page title with content container (not bleeding into the sidebar).

Accessibility & responsiveness

Ensure 4.5:1 contrast for text on colored backgrounds for badges and buttons.

Make the table responsive: at smaller widths collapse less important columns into a details panel or use horizontal scrolling with sticky first column.
