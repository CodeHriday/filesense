This layout follows a premium modern analytics dashboard pattern focusing on:

Clean white surfaces

Neutral gray sidebar

Soft, rounded cards with subtle shadows

Strong visual hierarchy

Vivid but controlled accent colors (green/blue/orange) for KPIs & charts

Excellent spacing & grid discipline

This is a consumer-grade aesthetic applied to enterprise data.

🎯 1. Layout Structure (Grid, Spacing & Hierarchy)
Page Layout:
Region	Description	Size
Top Header	Thin app bar with logo & time filter	Height: ~56–60px
Left Sidebar	Vertical navigation with grouped sections	Width: ~240–260px

Spacing System

Small: 8px

Sidebar item padding: 14px–16px vertically

🧠 8. Overall Design Principles Used Here

This dashboard reflects modern SaaS UI patterns:

✔ High whitespace → premium feel
✔ Minimal contrast → non-fatiguing
✔ Strong visual hierarchy
✔ Rounded corners everywhere
✔ Gentle shadows
✔ Unified color story (greens + whites + grayscale + vivid chart colors)
✔ Spacing discipline (8px step grid)
✔ Neutral sidebar, bright content
✔ Segmented KPI cards in a horizontal row
✔ No heavy borders → use shadow + spacing instead
